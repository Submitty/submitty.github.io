Release [v26.11.01](https://github.com/Submitty/Submitty/releases/v26.11.01)
adds a global Submitty Python Virtual Environment (venv) at `/usr/local/submitty/venv`, which is used by Submitty scripts, daemons, jobs, etc.

Previously, Submitty installed its Python dependencies to the global system environment. As of Ubuntu 24.04, this is considered bad practice because it can break system packages and cause unexpected issues. Thus, Submitty now uses a virtual environment in preparation for the migration to Ubuntu 24.04.

**Note:** *The update from Ubuntu 22.04 to Ubuntu 24.04 is planned for a future release.*

Activate the venv to use Submitty's Python scripts
by running `source /usr/local/submitty/venv/bin/activate`,
or call `/usr/local/submitty/venv/bin/python script.py` directly.

Users will continue to be able to run the following scripts without explicitly activating the venv:

- `/usr/local/submitty/bin/generate_repos.py`
- `/usr/local/submitty/bin/grading_done.py`
- `/usr/local/submitty/bin/regrade.py`
- `/usr/local/submitty/sbin/adduser.py`
- `/usr/local/submitty/sbin/adduser_course.py`

Follow these steps to reconfigure:

1. Edit your Apache configuration `/etc/apache2/sites-available/submitty.conf`, similar to the sample file: [https://github.com/Submitty/Submitty/blob/main/.setup/apache/submitty.conf](https://github.com/Submitty/Submitty/blob/main/.setup/apache/submitty.conf)

    ```
    # Global mod_wsgi configuration to use the Submitty virtual environment
    <IfModule mod_wsgi.c>
        WSGIPythonHome /usr/local/submitty/venv
    </IfModule>
    ```

2. Run the regular install script to update the main machine and all workers.

    ```
    sudo /usr/local/submitty/.setup/INSTALL_SUBMITTY.sh
    ```
