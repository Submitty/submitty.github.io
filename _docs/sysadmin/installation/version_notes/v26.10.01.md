title:  v26.10.01 > Apache & NGINX Configuration Updates
category: System Administrator > Installation Version Notes
---

Release [v26.10.01](https://github.com/Submitty/Submitty/releases/v26.10.01)
makes two changes.
It adds a configuration setting to limit the cookies that are passed to the NGINX server.
It also disables FastCGI connection reuse of Apache connections.
Follow these steps to reconfigure NGINX & Apache.


1. Edit your NGINX configuration `/etc/nginx/sites-available/submitty.conf` and add the
   `proxy_set_header` configuration line below inside of the `location /ws` block,
   similar to the sample file:
   [https://github.com/Submitty/Submitty/blob/main/.setup/nginx/submitty.conf](https://github.com/Submitty/Submitty/blob/main/.setup/nginx/submitty.conf)
   
    ```
    # Forward only the cookie the socket server reads. Its HTTP parser (Ratchet)
    # closes handshakes over 4096 bytes with a 413, and cookies that other sites
    # set on the same domain can push the handshake past that.
    proxy_set_header Cookie "submitty_websocket_token=$cookie_submitty_websocket_token";
    ```


2. Edit your Apache `/etc/nginx/sites-available/submitty.conf` to disable reuse as shown below, similar to the sample file:
   [https://github.com/Submitty/Submitty/blob/main/.setup/apache/submitty.conf](https://github.com/Submitty/Submitty/blob/main/.setup/apache/submitty.conf)

    ```
    # Define a matching worker for proxying requests. Keep connection reuse
    # off, because each Apache child process keeps its own pool of idle
    # connections, and they can tie up every PHP-FPM worker. max is a limit
    # per Apache child process, not a total. The number of PHP requests that
    # run at once is set by pm.max_children in PHP-FPM's pool config, at
    #       /etc/php/<PHP_VERSION>/fpm/pool.d/submitty.conf
    #
    # The part that is matched to the SetHandler is the part that
    # follows the pipe above. If you need to distinguish, "localhost; can
    # be anything unique.
    <Proxy "fcgi://localhost/" enablereuse=off max=20>
    </Proxy>
    ```


3. Run regular install script.

   ```
   sudo /usr/local/submitty/.setup/INSTALL_SUBMITTY.sh
   ```
