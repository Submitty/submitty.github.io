Release [v26.10.01](https://github.com/Submitty/Submitty/releases/v26.10.01)
adds a configuration setting to limit the cookies that are passed to the NGINX server.

Follow these steps to reconfigure the socket server.


1. Edit your NGINX configuration `/etc/nginx/sites-available/submitty.conf` and add the
   `proxy_set_header` configuration line below inside of the `location /ws` block,
   similar to the sample file:
   [https://github.com/Submitty/Submitty/blob/main/.setup/nginx/submitty.conf](https://github.com/Submitty/Submitty/blob/main/.setup/nginx/submitty.conf)
   
    ```
    # Forward only the cookie the socket server reads. Its HTTP parser (Ratchet)
    # closes handshakes over 4096 bytes with a 413, and cookies that other sites
    # set on the same domain can push the handshake past that.
    proxy_set_header Cookie "submitty_websocket_token=$cookie_submitty_websocket_token";
    ```

2. Run regular install script.

   ```
   sudo /usr/local/submitty/.setup/INSTALL_SUBMITTY.sh
   ```
